# User Prompt
> In the 'Friends' menu screen, add a text field for 
> 'Custom Friend 1'
> 'Custom Friend 2'
> 'Custom Friend 3'
> People who are not in fixed names, can add themselves here and track each other

# Walkthrough

## Summary of Changes
- **Updated `activity_friends.xml`**:
  - Restructured the inner container of the `ScrollView` to have a `vertical` orientation.
  - Added a "Custom Friends" section header below the two-column checklist.
  - Added three `EditText` fields (`et_custom_friend_1`, `et_custom_friend_2`, `et_custom_friend_3`) allowing users to input up to three custom friend names.

- **Updated `FriendsActivity.java`**:
  - Bound the new `EditText` fields in `onCreate`.
  - Loaded previously entered custom friend names from `SharedPreferences` so that they remain populated across sessions.
  - In the "Track Them" button click listener, read the text from these three inputs.
  - If they contain non-empty text, they are saved in `SharedPreferences` (to repopulate the fields next time) and are also appended to the `selected` set.
  - This effectively adds these custom user names to the `tracked_friends` list, enabling them to be tracked dynamically via MapLibre when location JSONs sync from Cloudflare or Matrix.
