# User Prompt
> on left side menu, add a new menu item (Below Friends) by label 'Clear Sessions'.
> On click of this, a POST request has to be sent to '<CLOUDFLARE_APP_URL>/clear'

# Walkthrough

## Summary of Changes
- **Updated `activity_main.xml`**: Added a new `LinearLayout` for the "Clear Sessions" menu item in the left-side navigation drawer, placing it right below the "Friends" menu item. It uses the `ic_menu_delete` icon for its visuals.
- **Updated `MainActivity.java`**:
  - Bound the new menu item to a variable `menuClearSessions`.
  - Added a click listener that closes the drawer and sends a POST request to `<CLOUDFLARE_APP_URL>/clear`.
  - Added a new method `sendCloudflareClear(String cloudflareUrl)` that builds the endpoint URL (appending `/clear` instead of `/update`), makes an HTTP POST request with an empty JSON body `{}`, and logs the outcome appropriately.
  - Showed a Toast notification confirming that the clear request has been sent to Cloudflare, or an error if the URL wasn't configured.
