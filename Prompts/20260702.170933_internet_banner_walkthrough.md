# User Prompt
if my internet is not on, then show a red banner with a message "No Internet Connection"

# Implementation Walkthrough: No Internet Connection Banner

## Overview
I have successfully implemented the dynamic red banner that appears when the device loses its internet connection.

## Changes Made
### 1. UI Updates
- **File**: `app/src/main/res/layout/activity_main.xml`
- Inserted a new `TextView` representing the red banner. It is placed seamlessly below the app title bar. By default, its visibility is set to `gone` so it remains hidden when there's an active connection. The background color is a bold red (`#D32F2F`) with clear white text for high visibility.

### 2. Logic Implementation
- **File**: `app/src/main/java/com/vypeensoft/friendtracker/MainActivity.java`
- Bound the new `TextView` (`tv_no_internet`) during `onCreate()`.
- Added `checkInitialNetworkState()` to detect if the internet is already disconnected when the app starts, immediately displaying the banner if necessary.
- Added `setupNetworkListener()` which utilizes Android's `ConnectivityManager.registerDefaultNetworkCallback()`. This seamlessly and efficiently monitors for network changes in the background and updates the UI on the main thread automatically without needing manual refreshes.

## Validation
To manually test this feature:
1. Open the app with Wi-Fi/Mobile Data on. Verify no banner is shown.
2. Turn off the internet connection from your device's quick settings. The red banner will appear instantly.
3. Turn the internet back on, and the banner will gracefully disappear.
