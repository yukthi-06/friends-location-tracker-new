# User Prompt
if my GPS/Location is not on, then show another red banner with a message "GPS/Location not enabled"

# Implementation Plan

## Goal Description
Add a dynamic red banner displaying "GPS/Location not enabled" when the device's location services are disabled.

## Proposed Changes

### UI Changes
- **File**: `app/src/main/res/layout/activity_main.xml`
- **Action**: Add a new `TextView` representing the GPS banner immediately below the No Internet banner. It will have `android:visibility="gone"` by default. Background will be red (`#D32F2F`), text will be white.

### Logic Changes
- **File**: `app/src/main/java/com/vypeensoft/friendtracker/MainActivity.java`
- **Action**: 
    - In `onCreate()`, bind the `tvNoGps` TextView.
    - Implement `checkInitialGpsState()` to check the location state on startup using `LocationManager`.
    - Implement `setupGpsListener()` using a `BroadcastReceiver` for `LocationManager.PROVIDERS_CHANGED_ACTION` to dynamically show or hide the banner when the GPS state changes.
    - Unregister the receiver in `onDestroy()`.

## Verification Plan
- Turn off GPS and verify the red banner appears.
- Turn on GPS and verify the banner disappears.
