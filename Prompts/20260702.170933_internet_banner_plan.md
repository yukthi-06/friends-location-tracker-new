# User Prompt
if my internet is not on, then show a red banner with a message "No Internet Connection"

# Implementation Plan

## Goal Description
Add a dynamic red banner displaying "No Internet Connection" when the device is disconnected from the internet.

## Proposed Changes

### UI Changes
- **File**: `app/src/main/res/layout/activity_main.xml`
- **Action**: Add a new `TextView` representing the red banner immediately below the title bar. It will have `android:visibility="gone"` by default. Background will be red (`#D32F2F`), text will be white.

### Logic Changes
- **File**: `app/src/main/java/com/vypeensoft/friendtracker/MainActivity.java`
- **Action**: 
    - In `onCreate()`, bind the `TextView`.
    - Implement `checkInitialNetworkState()` to check the connectivity on startup.
    - Implement `setupNetworkListener()` using `ConnectivityManager.registerDefaultNetworkCallback()` to dynamically show or hide the banner when the internet connection changes.

## Verification Plan
- Turn off internet and verify the red banner appears.
- Turn on internet and verify the banner disappears.
